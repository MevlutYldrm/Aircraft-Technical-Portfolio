# Aircraft-Technical-Portfolio
Havacılık Teknik Projeler Portfolyosu
Bu repo, AutoCAD ile gerçekleştirdiğim 3D uçak parçası tasarım çalışmalarımı ve teknik resim çıktılarını içermektedir.

Kullanılan Program: AutoCAD

İçerik: 3D modelleme teknikleri, teknik resim standartları, komponent tasarımı.

Amaç: Teknik resim okuma yetkinliğini ve komponent geometrisi analizini pratik etmek.
